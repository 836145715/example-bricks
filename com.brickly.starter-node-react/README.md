# Starter Node React

这是 `@syllm/create-brickly` 拼出来的官方样例：Node runtime + React/Vite UI + `full` 预设。目录里的 `runtime/` 与 `ui-src/` 是两层模板叠在一起，不是手写整包工程。

在 `ai-bricks/Brickly/` 下重生（先删本目录）：

```bash
npm run create-brickly -- ../../example-bricks/com.brickly.starter-node-react \
  --id com.brickly.starter-node-react \
  --name "Starter Node React" \
  --author Brickly \
  --runtime node \
  --ui react \
  --preset full \
  --platforms all \
  --schema ../specs/manifest.schema.json \
  --yes
```

Generated by create-brickly.

## 运行方式

Runtime 使用 Node SDK，入口由 manifest.runtime.entry 声明。

## UI 开发

```bash
cd ui-src
npm install
npm run build
```

构建产物会输出到 `ui/`，manifest 中的入口是 `ui/index.html`。

## 示例能力

- `hello`：返回一段最小可运行的问候结果。。参数：`name`（名称）: string；示例输入：`{"name":"Brickly"}`
- `analyze-text`：统计文本字符数、词数、行数，并返回常用转换结果。。参数：`text`（文本）: string，必填；示例输入：`{"text":"Hello Brickly"}`
- `transform-json`：解析 JSON，返回类型、键列表、格式化文本和紧凑文本。。参数：`json`（JSON）: string，必填；示例输入：`{"json":"{\"name\":\"Brickly\"}"}`
- `stream-demo`：演示 progress、chunk、output、取消检查和最终 result。。参数：`topic`（主题）: string，必填；示例输入：`{"topic":"Brickly SDK"}`
- `generate-report`：汇总主题和要点，返回 Markdown 报告。。参数：`title`（标题）: string，必填；`notes`（要点）: string，必填；示例输入：`{"title":"工具报告","notes":"支持 SDK"}`
